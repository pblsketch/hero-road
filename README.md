# 영웅의 길 — 영웅소설 서사 RPG

**만든이**: 박준일 (온양여자고등학교 국어 교사)

학생이 영웅소설의 주인공이 되어 **영웅의 일대기 일곱 단계**를 직접 밟아 나가는 고등학생용 학습 게임입니다.
도트 그림으로 된 **탑뷰 맵 RPG**입니다. 저잣거리·대궐·집·명산·수련장·군영·싸움터를 걸어 다니며 인물에게 말을 걸고, 자리를 골라 이야기를 정하고, 잡병과 적장을 실시간으로 벱니다. 1~5장에서 능력치를 어떻게 쌓았느냐에 따라 익힐 수 있는 **기술**이 달라집니다.
특정 작품이 아니라 영웅소설 일반의 관습을 다루고, 처음 고른 주인공의 성별에 따라 **남성 영웅소설의 길**과 **여성 영웅소설의 길**이 갈립니다.

| 어려운 점 | 게임 장치 |
|---|---|
| 일대기 7단계를 외우기만 하고 지문에서 못 찾는다 | 장 = 단계. 장이 끝날 때마다 전기수가 실제 작품의 대목 중 "방금 지나온 단계와 같은 대목"을 고르게 한다 |
| 작품마다 줄거리가 비슷해 뒤섞인다 | 일반 서사를 직접 살아 본 뒤 『유충렬전』·『홍계월전』 등의 작품 카드를 그 틀에 겹쳐 본다 |
| 여성 영웅의 '남장'이 왜 필요한지 추상적이다 | 딸의 길에만 남장 결심과 **의심 게이지**가 있다. 부마 간택·진맥 같은 탄로 계기를 직접 겪는다 |
| 남녀 차이를 한쪽만 경험하면 비교할 수 없다 | 반을 나눠(주소 `?path=m` / `?path=f`) 플레이한 뒤 디브리핑에서 서로의 길을 나눈다. 게임 안에서는 다른 길을 잠가 둔다 |

- 브라우저만 있으면 됩니다(설치 없음). 휴대폰(가상 조이스틱)·PC(키보드)·태블릿 모두 됩니다.
- **2차시**에 한 길을 끝까지 걷습니다. 1차시: 서장~4장(일대기 1~4단계), 2차시: 5장~결과. 4장이 끝나면 "1차시는 여기까지" 안내가 나오고, 다음 시간에 타이틀의 **이어 하기**로 5장부터 이어 갑니다.
- 진행 상황은 **그 브라우저에만** 저장됩니다(서버로 보내지 않음). 같은 기기·같은 브라우저에서 이어 해야 합니다.

## 실행하기

| 방법 | 설명 |
|---|---|
| 내 컴퓨터에서 | 폴더에서 `python -m http.server 8765`를 실행하고 http://127.0.0.1:8765 를 연다 |
| 파일로 | `index.html`을 더블클릭해도 되지만, 브라우저가 글꼴 파일을 막아 기기 글꼴로 보일 수 있다 |
| 반 나누기 | 주소 끝에 `?path=m`(아들의 길) 또는 `?path=f`(딸의 길)를 붙여 나눠 주면 서장에서 성별을 고르지 않고 그 길로 시작한다 |
| 바로가기 | `?ch=ch5`처럼 붙이면 그 장으로 바로 간다(ch0 서장, ch1~ch7). `?teacher=1`은 선생님용 켜기 |

## 구성 (2차시)

| 장 | 일대기 단계 | 맵에서 하는 일 | 새 장치 |
|---|---|---|---|
| 서장 이야기판이 열리다 | — | 종로 저잣거리: 전기수에게 가서 아들/딸 정하기, 세책점에서 이름 적기 | 방각본·세책점·요전법 이야기, 「○○전」 |
| 1장 충신의 가문 | 1 고귀한 혈통 | (아버지가 되어) 대궐 조회 → 집 사당에서 가문 내력 고르기 | 가문 내력(능력치) |
| 2장 하늘이 내린 아이 | 2 비정상적 출생 | (아버지가 되어) 명산의 절·산신각·칠성단 중 **직접 찾아가** 빌기 → 태몽 | 기자 치성, 태몽 |
| 3장 범상치 않은 아이 | 3 탁월한 능력 | 활터·서당·뒷동산 중 한 곳에서 재주 보이기 → 도사의 예언 | 재주 |
| 4장 무너진 가문 | 4 기아·죽을 고비 | 끌려가는 아버지(막을 수 없는 장면) → 불타는 밤, **자객을 피해 달아나기**(갈대숲/산길) | **1차시 끝** |
| 5장 은인과 스승 | 5 구출·양육자 | 강가 윤 처사의 집 → 산속 수련장: 허수아비 베기·병서·제단에서 수련 → **기술 익히기**, 신물, 허깨비 병사 → **허깨비 장수(적장전 익히기)** | 딸: **남장 결심** |
| 6장 다시 닥친 위기 | 6 자라서 다시 위기 | 대궐 과거 → 군영 → 싸움터에서 오랑캐 선봉대 → **호국 선봉장** | 딸: **의심 게이지** |
| 7장 영웅의 승리 | 7 위기 극복·승리 | 황성 앞 싸움 → **철목달 결전**(기력이 반 남으면 요술을 부리는 둘째 마당) → 대궐 → 집에서 재회 | 딸: **정체 탄로 뒤 갈래** |

남장하지 않는 갈래는 6·7장을 시댁 뒤뜰(피화당)에서 보냅니다. 뜰에 쳐 둔 나무 진 사이에서 오랑캐와 싸우고 적장을 굴복시킵니다.

**싸움**: 잡병(허깨비 병사·오랑캐 군사)은 **붉게 번쩍이면** 곧 공격합니다. 적장(허깨비 장수·호국 선봉장·철목달)은 공격 전에 땅에 **붉은 자리**(부채꼴·곧은 줄·원)를 먼저 보여 주니 그 밖으로 피하고, 공격이 끝난 빈틈에 벱니다. 칠 때마다 **기세**(보스 막대 아래 노란 줄)가 쌓여 가득 차면 적장이 비틀거립니다(피해 1.5배). 적장이 **기를 모으면**(노란 고리) 몰아쳐 베거나 **계책**으로 끊어야 하고, 못 끊으면 크게 내려찍습니다.

**기술 나무**: 武 무예(연환검 → 돌격 → 일기당천), 兵 병법(진법 → 복병 → 계책), 術 도술(부적 → 축지법 → 호풍환우). 2단계는 그 능력치 **3 이상**, 3단계는 **5 이상**이어야 하고 앞 단계를 먼저 익혀야 합니다. 기술 점수는 5장 수련 한 번에 1점(3점), 6·7장 잡병 싸움을 이기면 1점씩 모두 5점이라, 고르게 쌓은 학생과 한 갈래만 판 학생이 서로 다른 기술로 싸웁니다. 무예는 칼 피해와 기력, 병법은 기력과 받는 피해 줄이기, 도술은 기술을 더 자주 쓰는 데에도 쓰입니다.

**딸의 길 세 갈래**: 계속 활약하는 길(『홍계월전』) · 규방으로 돌아가는 길(『이학사전』) · 남장 없이 가는 길(『박씨전』). 갈래 끝에는 "이 길은 이 작품이 간 길"이라는 붉은 낙관이 찍힙니다. 『정수정전』은 정체를 밝힌 뒤 다시 출전하므로 규방 갈래의 기준으로 쓰지 않고, 딸의 길 낯선 대목과 작품 도감에만 넣었습니다.

**결과 화면(나의 「○○전」)**: 목차 엮기(내가 걸은 일곱 대목을 순서대로) → 다른 작품의 낯선 대목 3개에서 단계 찾기 → 방각본 표지와 목차, 전기수의 셈(첫 시도 정확도·천우신조·의심), 갈래 지도(걸은 길만 펼침), 한 줄 디브리핑 답 → **이미지로 저장**.

## 두 가지 방식

| 방식 | 대상 | 차이 |
|---|---|---|
| 처음 배우기 | 고1 공통국어 | 장 끝 물음에 지금 단계의 이름과 풀이가 보이고, 보기가 3개 |
| 깊이 읽기 | 고2·3 문학 | 단계 풀이를 숨기고 보기가 4개. 장마다 다른 작품의 낯선 대목에서 단계 찾기가 더 나오고, 연구 관점 질문(여성 영웅의 규방 귀환을 어떻게 볼 것인가)이 더해짐 |

## 실제와 상상의 구분

| 표시 | 뜻 |
|---|---|
| 붉은 낙관 `原作` | 실제 작품 카드. 줄거리를 오늘날 말로 새로 풀어 쓴 요약 |
| 한지 색 `작품 속 관습` | 적강, 기자 치성, 남장, 천우신조 같은 되풀이되는 관습(편람의 관습 사전) |
| 청록 `게임 설정 · 虛` | 전기수의 이야기판, 능력치·전투 규칙, 의심 게이지, 게임 속 인물 이름(조무린·윤 처사·윤선·윤 소저·철목달·호국) |
| 쪽빛 `해석` | 정답이 없는 질문. 채점하지 않음 |

- 성별 차이는 "여성은 원래 이렇다"가 아니라 "당대 작품들이 이렇게 그렸다"는 틀로 제시합니다.
- 게임 오버가 없습니다. 전투에서 기력이 다하면 **천우신조**(하늘의 도움)로 이어지고, 의심이 가득 차면 **탄로 위기** 사건이 옵니다. 모두 영웅소설의 관습입니다.
- AI가 그린 그림에는 글자를 넣지 않았고, 이야기 속 인물은 명나라 옷을 입고 있습니다(영웅소설 대부분이 중국을 배경으로 함). 전기수가 있는 이야기판만 조선 후기 저잣거리입니다.

## 만든 방법

- **설계**: `design/기획서_v2.md`(탑뷰 맵 RPG로 바꾼 설계), `design/기획서_v1.md`(인터뷰로 확정한 사항, 장 구성, 시스템). 처음 기획안은 `영웅의 길 — 영웅소설 서사 RPG 기획안 v0.md`.
- **도트 그림(맵·인물)**: Codex CLI의 이미지 생성(gpt-image-2)으로 인물마다 걷기 3방향×4장(+ 베기 3방향×3장) 시트와 소품 시트를 만들고, `tools/process_sprites.py`가 마젠타 배경을 빼고, 빈 틈으로 프레임을 자르고, **발밑 피벗**을 맞추고, 땅 한 칸 32px(어른 키 48px)에 맞춰 줄이고, 색 수를 줄여 아틀라스(`assets/sprites/`, `js/data/sprites.js`)로 묶습니다. 프롬프트는 `tools/make_sprites.py`. 오른쪽 모습은 왼쪽을 뒤집어 씁니다. 땅 타일은 코드로 그립니다(`js/game/tiles.js`).
- **엔진**: `js/game/world.js` — 캔버스 탑뷰, 정수 배율 확대, 발밑 y 정렬, 충돌, 카메라, 가상 조이스틱, 실시간 싸움의 손맛(히트 스톱·흰 번쩍임·넉백·화면 흔들림·파편·찌그러짐). 대사·선택·수련은 예전 단계 실행기(`js/game/steps.js`)를 대화창에 그대로 띄웁니다.
- **기술·적장전**: `js/game/combat.js` — 기술 나무 화면, 기술 9가지, 복병 군사, 적장의 공격 예고(붉은 자리)·기세·비틀거림·둘째 마당, 결정타의 느린 화면. 철목달 도트는 따로 그렸고(`sp_boss`), 허깨비 장수·호국 선봉장은 잡병 시트를 크게 다시 줄여 씁니다.
- **초상·장면 그림**: Codex CLI의 이미지 생성(gpt-image-2), 방각본 고소설 목판 삽화풍. 프롬프트 `tools/make_prompts.py` → 생성 `tools/genqueue.ps1`(실패하면 `tools/genretry.ps1`) → 줄이기 `tools/process_assets.py`. 화풍 시안 4종은 `design/style-samples/`.
- **소리**: 지금은 가야금·대금·해금·장구·북·징을 브라우저에서 합성합니다(소리 파일 없음). 국립국악원 디지털 이음(공공누리 제1유형)의 실제 연주 악구로 바꾸는 계획은 `design/bgm_plan.md`에 있습니다(선생님 확인 뒤 내려받기). 합성 엔진은 같은 만든이의 「사씨남정기: 지워진 이름」에서 가져왔고, 곡 13개는 새로 지었습니다(`js/core/audio.js`의 `TRACKS`). 이야기판(굿거리) → 가문(중모리) → 태몽(장단 없음) → 어린 시절(세마치) → 모함·몰락(계면조) → 수련(중중모리) → 과거(굿거리) → 전투(자진모리) → 결전(휘모리) → 승리(중모리), 규방(계면조 중모리).
- **글꼴**: Noto Serif KR과 나눔손글씨 붓에서 게임에 쓰인 글자만 남긴 부분 글꼴(SIL OFL 1.1, `assets/fonts/OFL.txt`).

## 알려진 한계

- 적장전·기술은 게임 설정이며 수치는 자동 플레이로만 맞췄습니다. 실제 학생의 조작 실력에 따라 `js/data/bosses.js`의 hp·빠르기를 조절하세요(천우신조가 있어 막히지는 않습니다).
- 장 안에서의 위치는 저장하지 않습니다. 중간에 끄면 다시 열 때 그 장의 **다음 목표**부터, 그 목표가 있는 맵의 시작 자리에서 이어집니다.
- 도트 인물·소품은 AI가 그린 그림을 줄인 것이라, 걷는 모습이 프레임마다 조금씩 흔들릴 수 있습니다.
- 작품 세부(인물명·사건 순서)는 이본마다 다릅니다. 작품 카드는 백과사전·연구 자료를 바탕으로 한 요약이니 교과서 본문과 대조해 주세요.
- 『박씨전』은 영웅의 일대기 일곱 단계와 딱 맞지 않는 작품이라, 맞대기 어려운 단계는 비워 두었습니다.
- 『이학사전』은 교과서·수능 수록 여부를 확인하지 못했습니다. 학생에게 낯선 작품일 수 있습니다.
- 작품 사실 확인 자료(`design/research/01_작품_사실확인.md`)에서 '추정'으로 표시한 항목(『홍계월전』의 홍무·양씨·맹길, 『조웅전』 도사들의 역할 등)은 게임 카드에 넣지 않았거나 일반적인 표현으로 적었습니다.
