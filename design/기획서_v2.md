# 영웅의 길 — 기획서 v2 (탑뷰 맵 RPG)

v1(글로 읽는 비주얼 노블 구조)을 **실제로 걸어 다니는 탑뷰 맵 RPG**로 바꾼 설계. 이야기·작품 카드·장 끝 물음·결과 화면은 v1 그대로 두고, 그 위에 맵·이동·실시간 싸움 층을 얹었다.

## 1. 바뀐 결정 (인터뷰)

| 물음 | 결정 |
|---|---|
| 형태 | **탑뷰 맵 RPG**: 캐릭터를 움직여 NPC와 말하고, 장소를 골라 이야기를 정한다 |
| 조작 | 시중 게임처럼: 휴대폰은 왼쪽 **가상 조이스틱** + 오른쪽 행동 단추, PC는 방향키·WASD + E/Space/Q |
| 수업 시간 | **2차시**. 1차시 서장~4장(일대기 1~4단계), 2차시 5장~결과 |
| 전투 | **잡병은 실시간 액션, 적장은 카드**(v1의 카드 전투를 그대로 씀) |
| 그림 | 맵·인물은 **도트(픽셀 아트)**, 대화 초상·장면은 v1의 방각본 목판 삽화 그대로 |
| 참고 | 게임 에셋 영상(https://youtu.be/71SD018yoVA): 시트 생성 → 배경 제거 → 프레임 자동 검출 → 발밑 피벗 → PPU 기준 축소, 손맛 6가지 |

## 2. 구조

```
QUESTS[장] = 시작 맵 + 인물 배치(cast) + 목표(beat) 목록
beat = { goal: 화면 위 목표 글, 할 일, steps: [story.js 단계 id…] }
할 일: talk(말 걸기) · at(살피기) · go(밟기) · pick(자리 골라 선택) · fight(실시간 싸움)
       · train(수련터 세 곳) · escape(쫓기며 달아나기) · auto(바로)
```

- 목표를 이루면 묶인 단계들이 **대화창**(화면 아래 한지 판, 전투는 전체 화면)에서 v1 단계 실행기로 펼쳐진다. 그래서 대사·선택지·이름 짓기·카드 전투 코드를 하나도 버리지 않았다.
- **공간 선택(pick)**: v1의 선택지를 장소로 옮겼다. 2장 기자 치성은 절·산신각·칠성단 중 **걸어가서 비는 곳**이 곧 선택이고, 3장 재주는 활터·서당·뒷동산, 4장 도주는 갈대숲·산길 출구. 대화창에는 지도에서 고른 선택지가 표시된다(배운 내용을 글로도 확인).
- 이야기 단계는 빠짐없이 어느 목표엔가 묶여 있어야 한다(`tests/content.mjs`가 검사).
- 이어 하기: 장 안의 위치는 저장하지 않고, 끝낸 목표(`done['b:목표id']`)까지 기억해 다음 목표부터 잇는다.

## 3. 장별 맵

| 장 | 맵 | 조종하는 인물 | 핵심 놀이 |
|---|---|---|---|
| 서장 | 종로 저잣거리 | 이야기 듣는 사람(학생 자신) | 전기수 → 세책점. 구경꾼·책장수에게서 방각본·세책·요전법 이야기 |
| 1장 | 대궐 → 집 | 아버지 | 조회(충신과 간신) → 사당(가문 내력) → 부인 |
| 2장 | 명산 → 집(밤) | 아버지 | 세 곳 중 걸어가서 빌기 → 태몽 |
| 3장 | 집과 마을 | 아이 | 활터·서당·뒷동산에서 재주 → 대문 밖 도사 |
| 4장 | 집(낮 → 불타는 밤) | 아이 | 막을 수 없는 장면 → 자객 셋을 피해 달아나기(아이는 싸울 수 없다) |
| 5장 | 강가 → 수련장 | 아이 → 젊은 영웅 | 구출 → (딸) 남장 결심 → 수련 3회(허수아비를 직접 벤다) → 신물 → 허깨비 병사(실시간) → 허깨비 장수(카드) |
| 6장 | 대궐 → 군영 → 싸움터 / (c) 시댁 뒤뜰 | 젊은 영웅 → 대원수 | 과거·부마 간택 → (딸) 강가 목욕 권유 → 선봉대 두 물결 → 선봉장 |
| 7장 | 황성 앞 → 대궐 → 집 / (c) 뒤뜰 | 대원수 / 도사 부인 | 성문 앞 싸움 → 철목달 결전 → 천자 → 재회 → (딸) 진맥·정체 탄로·갈래 |

## 4. 실시간 싸움

- 잡병: 허깨비 병사(기력 2), 자객(쫓기만 함), 오랑캐 군사(기력 3). 다가와서 **0.4초 동안 붉게 번쩍인 뒤** 벤다(피할 틈).
- 주인공: 기력 = 10 + 무예 + 병법(+3 신갑). 칼 피해 = 1 + (무예 3 이상) + (무예 5 이상). 병법 5 이상이면 받는 피해 1 줄임. 도술 2 이상이면 부적(둘레의 적을 밀쳐 내며 피해, 도술이 높을수록 자주).
- 기력이 다하면 **천우신조** 창 → 기력이 다 차고 적이 밀려난다(게임 오버 없음, 횟수만 기록).
- 손맛(영상): 히트 스톱(맞힘 0.055초, 쓰러뜨림 0.11초), 흰 실루엣 번쩍임, 넉백, 화면 흔들림, 파편(불꽃·먹물), 찌그러짐(베는 순간·맞는 순간), 피해 숫자, 먼지. 카드 전투에도 초상 번쩍임·베는 빛·피해 숫자·붉은 번쩍임·짧은 멈춤을 더했다.

## 4-2. 기술 나무와 적장전 (v2.1, 사용자 요청: "스탯을 어떻게 쌓느냐에 따라 다른 스킬", "보스전을 실시간으로")

- 기술 9가지 = 3갈래(武·兵·術) × 3단계. 2단계 능력치 3 이상, 3단계 5 이상 + 앞 단계. 기술 점수 5점(수련 3, 6·7장 잡병 싸움 승리 2). 단추 기술은 셋까지(Q·R·F).
  - 武: 연환검(늘: 셋째 베기 2배) · 돌격(내달리며 벰, 무적) · 일기당천(한 바퀴 두 번 베기)
  - 兵: 진법(늘: 기력 +4, 받는 피해 −1) · 복병(군사 둘 10초) · 계책(모두 멈춤, 기 모으는 적장 무너뜨림)
  - 術: 부적(둘레 밀쳐 내기) · 축지법(순간 이동 회피) · 호풍환우(화면 전체 피해 + 느리게)
- 5장 수련이 끝나면 기술 익히기 화면이 열리고, 점수를 얻었을 때 익힐 수 있는 기술이 있으면 다시 열린다.
- 카드 전투를 **맵 위 실시간 적장전**으로 바꿨다(카드 규칙은 글로 읽는 방식에만 남김).
  - 적장의 수: 부채꼴 베기 · 세 번 찌르기 · 돌진(벽에 부딪히면 비틀) · 내려찍기 · 요술(벼락 여러 곳) · 부하 부르기 · **기 모으기**(카드 전투의 "기를 모음 → 강공 / 계책으로 무너뜨림"을 실시간으로 옮김)
  - 공격 전 붉은 자리로 예고, 끝난 뒤 빈틈. 기세가 차면 비틀거림(피해 1.5배). 철목달은 기력 반에서 둘째 마당(더 빠름, 요술).
  - 허깨비 장수(5장)는 익히기용: 예고가 길고, 수마다 도사의 한 줄 안내.
  - 결정타: 느린 화면 + 흰 번쩍임 + 먹물 파편. 천우신조는 그대로.

## 5. 도트 에셋

- PPU 32(땅 한 칸 32px). 어른 48~52px, 아이 36px. 걷기 3행(아래·왼쪽·위)×4, 공격 3행×3. 오른쪽은 왼쪽 반전.
- 인물 29종(주인공 8모습 + 조연·주민·군사 21), 적 3종, 소품 34종(건물 6·자연 12·물건 16).
- 생성: `tools/make_sprites.py` → `tools/genqueue.ps1 -Manifest tools/manifest_sprites.tsv` (인물은 목판 초상을 "의상만 참고"로 붙여 같은 옷차림 유지)
- 가공: `tools/process_sprites.py` (마젠타 제거·스필 정리 → 투영 빈틈으로 프레임 검출 → 발밑 12% 줄의 가운데를 피벗으로 → 첫 프레임 키 기준 같은 배율로 BOX 축소 → 40색 팔레트 → 8열 아틀라스 + `js/data/sprites.js`)
- 땅 타일은 코드로 그린다(`js/game/tiles.js`): 풀·꽃밭·흙길·박석·마루·모래·싸움터·밭·깔개·다리·물(움직임)·담장(앞면/윗면)·울타리(가로/세로)·산울타리·벼랑.

## 6. 화면

- 캔버스 한 장을 **정수 배율**로 키운다(휴대폰 세로 가로 12칸 안팎, PC 20칸 안팎). 한글 이름표만 원래 해상도로 또렷하게.
- 위: 장·단계 + 지금 목표, 목차·편람·설정. 그 아래 기력(싸울 때)·능력치·신물·의심 게이지.
- 목표 표시: 노란 **!** 와 이름표, 화면 밖이면 가장자리 화살표. 말 걸 수 있는 사람은 가까이 가면 "…".
- 밤: 어두운 막에 주인공·등불·불길 둘레만 밝힘(2장 태몽, 4장 화재, c 갈래 6장).
