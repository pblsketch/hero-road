## 2. 한 줄 콘셉트와 틀

저잣거리의 **전기수**(조선 후기 소설을 읽어 주던 이야기꾼)가 주인공 자리가 비어 있는 이야기책을 펼치고, 듣는 학생이 주인공이 되어 영웅의 일곱 걸음을 밟는다. 전기수는 장이 끝날 때마다 가장 궁금한 대목에서 멈추고(요전법) "지금은 몇 번째 걸음이오?"라고 묻는다.

- 전기수·요전법은 실제 기록(조수삼 『추재기이』)에 있는 관습을 빌린 **게임 설정**이다(청록 표시).
- 게임 속 이야기는 특정 작품이 아니라 여러 영웅소설의 관습을 모아 새로 지은 것이다. 실제 작품은 **붉은 낙관** 카드로만 보여 준다.

## 3. 핵심 루프

| 층위 | 루프 |
| --- | --- |
| 30초 | 한 줄 읽기 → 고르기(능력치·의심이 변함) |
| 5분(한 장) | 일대기 한 단계를 살아 봄 → 장 끝 **전기수의 물음**: 실제 작품의 대목 3~4개 중 "방금 지나온 단계와 같은 대목" 고르기 → 작품 카드 열림 (깊이 읽기: 다른 작품의 낯선 대목 1개 단계 찾기) |
| 한 판(40분) | 서장 + 7장 → 결과: 목차 엮기(내 일곱 대목을 순서대로) → 낯선 대목 3개 → 표지·셈·한 줄 답 → 이미지 저장 |

장 끝 물음을 "몇 장이니까 몇 단계"로 맞힐 수 없게, **작품의 실제 대목**을 읽고 같은 단계를 고르게 했다(인출 연습 + 전이).

## 5. 시스템

### 5-1 능력치
무예(武)·병법(兵)·도술(術), 1에서 시작해 최대 7. 1~3장 선택으로 +1씩, 5장 수련 3회로 +1씩. 전투 카드의 세기 = 기본값 + 능력치 × 배율.

### 5-2 카드형 턴제 전투(군담)
- 한 턴에 카드 1장. 손에는 능력치 비율로 뽑은 카드 3장 + 아직 안 쓴 신물 카드.
- 적의 다음 행동(공격·강공·기를 모음·요술·막기)을 미리 보여 준다 → 반사신경 없이 수 읽기만.
- 카드: 武 칼 휘두르기·일기당천(武3 이상) / 兵 진법(막기)·계책(큰 공격·요술 무너뜨림) / 術 부적(회복)·풍운조화(약화)·둔갑술(術3 이상, 회피). 신물: 신검·천서·신갑.
- 기력이 다하면 **천우신조**: 기력 60% 회복 + 적 한 턴 쉼, 결과에 횟수만 기록.
- 적: 허깨비 장수(대련 16) · 호국 선봉장(26) · 오랑캐 군사들(c, 22) · 적장 철목달(36 / c 32) · 다시 쳐들어온 적군(a, 22).
- 밸런스(`tests/balance.mjs`, 능력치 합 9의 여러 배분 × 200판 모의실험): 7장 결전이 적의 행동을 읽고 고르면 3~8턴, 아무 카드나 골라도 4~14턴. 천우신조는 아무거나 고를 때 0~14%. 무예만 올리면 가장 빠르고(3~4턴), 병법 위주는 수를 읽을 때 크게 빨라진다(9턴 → 3.5턴).
- 선생님용: "바로 이기기".

### 5-3 의심 게이지(딸의 길, 남장 중)
남장 결심(5장)부터 보인다. 부마 간택(+10~30), 군영 목욕 권유(+10~25) 같은 사건에서 오른다. 100이 되면 **탄로 위기** 사건(윤선이 막아 줌)이 일어나고 60으로 내려간다. 7장의 진맥 탄로는 게이지와 상관없이 반드시 오지만, 가장 높았던 의심에 따라 천자의 첫마디가 달라진다. 아들의 길에는 이 게이지가 없다는 것 자체가 절차적 수사학이다.

### 5-4 갈래와 잠금
- 결과의 **갈래 지도**: 내가 걸은 길만 펼치고, 나머지는 "？ 잠긴 길"로 개수만("이 이야기에는 4개의 길이 있었어요").
- 작품 도감: 다른 성별의 작품, 다른 갈래 전용 작품은 잠긴다. 딸의 길 학생에게는 『홍계월전』 7단계(계속 활약 결말)를 장 끝 물음의 보기에서도 빼서 미리 보여 주지 않는다.
- 선생님용: 모든 장·갈래 열기, 편람 "모든 갈래" 탭.

### 5-5 인출 연습
1. 장 끝 전기수의 물음: 대표 작품의 대목 중 같은 단계 고르기(처음 배우기 3지, 깊이 읽기 4지·단계 풀이 숨김). 두 번 틀리면 정답이 빛나고 '도움'으로만 기록.
2. 깊이 읽기: 장마다 다른 작품의 낯선 대목 1개 단계 찾기(7칸).
3. 결과: 목차 엮기(내 일곱 대목 → 순서), 낯선 대목 3개.

## 6. 표시 체계(사실·관습·설정·해석)

| 표시 | 뜻 |
| --- | --- |
| 붉은 낙관 `原作` | 실제 작품 카드, 갈래 끝 "이 길은 『○○』이 간 길" |
| 한지 색 `작품 속 관습` | 여러 작품에 되풀이되는 관습(관습 사전 21항목) |
| 청록 `게임 설정 · 虛` | 전기수 틀, 능력치, 전투 규칙, 의심 게이지, 게임 속 인물 이름(조무린·윤 처사·윤선·윤 소저·철목달·호국) |
| 쪽빛 `해석` | 디브리핑 질문, 여성 의식의 의의와 한계 |

성별 차이는 "여성은 원래 이렇다"가 아니라 "당대 작품들이 이렇게 그렸다"로 제시한다.

- 빌드 도구 없음, `file://`로도 열림, GitHub Pages 배포 가능.
- 글 속 자리 `{성명} {이름} {호} {공명} {남장명} {부} {아이} {전}`와 조사 `{이름:을}` 자동 맞춤.
- 주소: `?teacher=1` 선생님용, `?path=m|f` 길 고정(반 나누기), `?ch=ch5` 장 바로가기, `?result=1`.

## 8. 에셋

Codex CLI 내장 image_gen(gpt-image-2), 방각본 목판 삽화풍. 인물 초상 20장(1024→320 webp), 장면 18장(1536×1024→1280 webp), 타이틀 1장(세로). 인물 일관성은 화풍 시안 A(네 인물 라인업)를 참조 이미지로 `same`/`style`/`scene` 방식으로 넘겨 맞췄다. 그림에는 글자를 넣지 않는다. 종이 질감·아이콘·공유 그림은 스크립트로 만든다.

## 9. 리서치로 확정한 것과 남은 일
